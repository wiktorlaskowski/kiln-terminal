# Kiln Terminal
## Source code in "Source" branch, click the dropdown and select "Source" (https://github.com/wiktorlaskowski/kiln-terminal/tree/Source)
### A simple terminal app that integrates with the UI

### Install insturction
run `echo "deb [trusted=yes] https://wiktorlaskowski.github.io/kiln-terminal/ ./" | sudo tee /etc/apt/sources.list.d/kiln.list`
### Then run apt update
run`sudo apt update`
### Then perform the install
run `sudo apt install kiln-terminal`
